# XephiraOS Official Website & Download Portal

Official source repository for [xephiraos.github.io](https://xephiraos.github.io).

## Design System
- **Engine**: Kyant0 Pure Liquid Glass (`liquid-glass.css`)
- **Optics**: Meniscus refraction, analytic normal gradients, specular rim sheen, and crystal-clear water translucency
- **Aesthetic**: Ultra-modern monochrome dark theme with cyan/blue accents
- **Typography**: Outfit, Inter, and JetBrains Mono

## Pages
- `index.html`: Official landing page featuring interactive 3D phone canvas with Kyant0 Settings preview
- `downloads.html`: Official download portal with real-time search, OEM filter chips, device specs, GApps vs Vanilla flavor selector, direct ROM download links, and SHA-256 verification
