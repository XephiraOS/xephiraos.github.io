INSTALLATION PROTOCOLS

How to Flash XephiraOS

Follow the recommended procedure for your installation type to ensure a pristine optical experience.

📦 Recovery Sideload

Recommended for clean upgrades and migrations from stock or other custom ROMs.

  1. Reboot phone to Xephira Recovery or TWRP: adb reboot recovery
  2. Wipe Dalvik/ART Cache, Data, and System partitions.
  3. Select Apply update from ADB and sideload: adb sideload XephiraOS-1.0-*.zip
  4. Reboot to System and experience Pure Liquid Glass.

⚡ Fastboot Factory Flash

Ideal for Google Pixel, OnePlus, and partitioned A/B devices directly from terminal.

  1. Reboot device into bootloader mode: adb reboot bootloader
  2. Extract the downloaded Fastboot ROM archive.
  3. Run the automated installer script: ./flash-all.sh # Linux / macOS
    flash-all.bat # Windows
  4. Wait for partitions to flash and device to auto-boot.

🌐 Universal GSI (Treble)

Compatible with any Android device with Project Treble v2.0+ support.

  1. Reboot into Fastbootd mode: fastboot reboot fastboot
  2. Erase and flash system image: fastboot erase system
    fastboot flash system system.img
  3. Wipe userdata partition to prevent bootloops: fastboot -w
  4. Reboot system: fastboot reboot
